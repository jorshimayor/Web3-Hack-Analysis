# EVM Track

Use this track for incidents reproduced with Foundry, mainnet forks, and transaction-level PoCs.

## Structure

- `template/`: base starter for new EVM cases.
- `ups/`: seeded from the current UtopiaSphere workspace.
- `belong/`: starter for the next target.

## Standard PoCs

- `01_ReproduceState.t.sol`
- `02_ExploitPath.t.sol`
- `03_ProfitValidation.t.sol`
- `04_MitigationCheck.t.sol`
